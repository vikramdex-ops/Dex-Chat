## Type

The website uses **Outfit** (display/body), **Cormorant Garamond** (editorial accents) and **JetBrains Mono**.
The app bundles Outfit and JetBrains Mono locally (both SIL OFL) so it renders identically offline; body text
falls back to Segoe UI Variable to stay native on Windows 11.
